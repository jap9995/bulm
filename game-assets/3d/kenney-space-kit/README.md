# @anabis/kenney-space-kit-mirror

> **This is an unofficial mirror.** It is not made, maintained, or endorsed by
> Kenney. The original asset pack is available at
> **https://kenney.nl/assets/space-kit**. Please download it there, and consider
> supporting Kenney: https://kenney.nl/support

Mirror of **Kenney's Space Kit (v2.0)**, released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Files are
unmodified, except that the `.url` shortcut files were removed.

## Contents

`assets/` contains `Models`, `Isometric`, `Side`, `Preview.png`, `Sample.png`,
and the original `License.txt`.

## Usage

```sh
npm install @anabis/kenney-space-kit-mirror
node -e "console.log(require('@anabis/kenney-space-kit-mirror').assetsDir)"
```
