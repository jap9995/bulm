# 《问道长生》拜访 NPC 的日常互动

> 本文补齐 [README](../README.md) 第 8.1 节待办的第 3 条：玩家去「拜访人物」时，**没有触发关系线事件的话会发生什么；好感平时怎么涨；送什么礼、谁喜欢什么**。
> NPC 的身份、关系线和阶段事件见 [内容扩展](content-expansion.md) 第四节；阵营好感见 [系统与数值](systems.md) 第 16 节；关系线事件怎么排进剧情位见 [事件抽取规则](event-draw.md) 2.2。

---

## 一、设计目标

- **关系线由事件推动，日常互动只负责「保温」。** 好感阶段事件（≥30 / ≥60 / ≥90）和终章是每位 NPC 的核心内容，日常互动不能替代它们，只能让玩家在两次事件之间有事可做，并把好感慢慢推到下一个门槛附近。
- **每次拜访都要有实际结果**（开发原则第 1 条）：不是只读一句寒暄。
- **不同的人，相处方式不同**：每位 NPC 有一项专属的往来方式和自己的喜好，送错东西会适得其反。

---

## 二、能拜访谁、在哪里

「拜访人物」只能找**已经认识**（发生过首遇）、**还活着**、**好感 > -50**（不是敌对）的 NPC。到达一个地点后，底部功能区的「拜访人物」会列出此刻在这里的人。

| NPC | 在哪里能拜访 | 什么时候开始能拜访 |
|---|---|---|
| 01 柳寒衣 | 山野或问剑宗，**每 6 次行动随机换一次地方**（与集市刷新同步） | 首遇之后 |
| 02 白芷 | 集市；拜师后也在丹鼎门 | 首遇之后 |
| 03 钱多多 | 集市 | 首遇之后 |
| 04 无名老丐 | **不能拜访**。他只会在你不知情时出现，考验走剧情位（事件抽取规则 2.2） | — |
| 05 苏夜璃 | 血煞宗地界；青冥秘境开放期间也在秘境 | 好感 ≥ 30 之后（之前她不会给你好脸色） |
| 06 赵承霄 | 集市 | 只有进入和解线之后 |
| 07 林小婉 | 问剑宗（被你救下之后加入） | 被你救下之后 |
| 08 血煞老人 | **不能拜访** | — |
| 09 玄清真人 | 问剑宗 | 你成为问剑宗弟子之后 |
| 10 阿九 | 山野 | 好感 ≥ 30（化形）之后 |
| 11 星衍子 | 集市；玄机阁弟子也可以在玄机阁找到他 | 首遇之后 |
| 12 小石头 | 凡人村落 | 首遇之后 |
| 道侣 | 洞府；没有洞府时在你所属的宗门 | 结为道侣之后 |

此刻在场的 NPC 一个都没有时，「拜访人物」按钮置灰，显示「这里没有相熟的人」。

## 三、一次拜访的流程

拜访人物耗时 0.25（× 时间系数，systems 1.3）。选定一位 NPC 后：

1. **先看有没有就绪的关系线事件。** 这位 NPC 有已就绪的阶段事件、终章或连环后续时，**直接触发**，本次拜访到此为止。这是推进关系线最直接的方式：剧情位在拜访时视为 100% 触发（事件抽取规则 2.2 的概率表只适用于外出探索等普通行动）。
2. **没有的话，进入日常互动**：从下面四种往来里**选一种**，一次拜访只做一件事。

| 往来 | 内容 | 详见 |
|---|---|---|
| 叙话 | 聊几句，好感小幅上升；有一定概率听到有用的闲话 | 第四节 |
| 送礼 | 送一件背包里的物品，按对方的喜好改变好感 | 第五节 |
| 专属往来 | 每位 NPC 不一样：切磋、问诊、买情报、算卦、指点…… | 第六节 |
| 告辞 | 什么都不做，不改变好感（耗时照算） | — |

## 四、叙话

### 4.1 好感变化

| 情况 | 好感 |
|---|---|
| 距离上次和他叙话 ≥ 4 次行动 | +3 |
| 距离上次叙话不足 4 次行动 | +1（「你怎么又来了」） |
| 道心与对方的立场相差很远（见 4.2） | 上面的数值减半，向下取整，最少 +0 |

### 4.2 合不合拍

| NPC | 立场 | 「相差很远」指 |
|---|---|---|
| 白芷、林小婉、玄清真人 | 正 | 你的道心 ≤ -30 |
| 苏夜璃 | 邪 | 你的道心 ≥ 50 |
| 其余 NPC | 不在意 | — |

### 4.3 闲话

每次叙话有 **30%** 概率听到一句闲话。闲话从这位 NPC 的「闲话池」里抽，**每条都带一个小结果**：

| 闲话类型 | 结果 | 例子（谁会说） |
|---|---|---|
| 指路 | 把一个已就绪的宿命或关系线事件的地点告诉你，显示在状态栏 | 钱多多：「听说你要找的那个人，最近常在落霞谷出没。」 |
| 透露 | 预先告诉你某个探索地点下一次的事件类别（和天赋「灵觉敏锐」的效果相同，只生效一次） | 柳寒衣：「山里那头大家伙又出来了。」 |
| 小物件 | 随手给你一件黄阶物品 | 白芷：「多炼了两颗，拿去。」（回春丹 ×1） |
| 心事 | 好感额外 +2，并在人生日志里记一笔 | 林小婉讲起被血煞宗追杀的那一夜 |

每位 NPC 的闲话池写 4–6 条，属于新增的文字内容，**需要另外写**。写法遵守 README 第 6 节的写作约定。

## 五、送礼

### 5.1 规则

- 送出背包里的一件物品（一次一件，可以是一叠里的一个）。
- 按对方的喜好改变好感：

| 喜好 | 好感 |
|---|---|
| 心头好 | +15；同一个大境界内第二次起只有 +8 |
| 喜欢 | +8 |
| 一般 | +3 |
| 讨厌 | -5；第二次送讨厌的东西 -10 |

- **冷却**：同一位 NPC，两次送礼之间至少相隔 3 次行动。冷却中送礼，对方会收下，但好感 +0（「你上回送的还没用完呢」）。
- 送出的物品就没了。送功法残卷、丹方这类「知识」时，你自己学会的不受影响，只是那一张残卷、那一页丹方给了对方。

### 5.2 每位 NPC 的喜好

只用 systems 第 3 节物品表里已有的物品，不新增物品。表里没列到的物品都按「一般」。

| NPC | 心头好 | 喜欢 | 讨厌 |
|---|---|---|---|
| 柳寒衣 | 玄阶及以上的剑类武器（例如秋水；他自己的寒衣遗剑除外） | 剑道功法残卷、五雷符 | 丹药（「剑客只信手中剑」） |
| 白芷 | 九叶灵芝 | 凝露草、赤血参、灵泉水、丹方 | 虎狼之药 |
| 钱多多 | 玄阶及以上的装备、饰品 | 任何买入价 ≥ 50× 的物品 | 不值钱的东西（买入价 < 10×） |
| 苏夜璃 | 清心丹、续命丹（她体内有血蛊） | 饰品、魔道功法残卷 | 正道宗门的功法残卷 |
| 赵承霄 | 破境丹 | 玄阶及以上的武器 | 黄阶的任何东西（「这种东西也拿得出手？」） |
| 林小婉 | 回春丹（当年那一枚的情分） | 剑类武器、青云道袍、清心丹 | — |
| 玄清真人 | 剑道功法（玄阶及以上）的残卷 | 灵泉水、清心丹 | 魔道功法残卷、血煞幡 |
| 阿九 | 灵兽丹 | 灵兽肉、灵泉水 | **妖兽材料、妖兽内丹**（-15，而不是 -5：那是她同族的身体） |
| 星衍子 | 天外陨铁、傀儡核心 | 符箓 | — |
| 小石头 | 黄阶功法（残卷或完整功法） | 回春丹、聚气丹 | — |
| 道侣 | 按这位 NPC 本人的喜好 | — | — |

### 5.3 送给小石头的东西会帮他成长

content-expansion NPC 12 写着「你在他身上投入的资源（功法、丹药、陪伴时间）会决定他最终的成就」。送礼就是一种投入：

- 送他功法（残卷或完整功法）、丹药，每件除了好感，再记 1 点「栽培」。
- 叙话、指点（第六节）各记 1 点「陪伴」。
- 小石头最终的成就按「栽培 + 陪伴」的总数决定，阈值见 [平衡验收指标](balance-targets.md) 6.6。

## 六、专属往来

每位 NPC 有一种只有他才有的往来方式，按好感逐步开放。专属往来同样每次拜访只能做一次。

| NPC | 专属往来 | 开放条件 | 内容 |
|---|---|---|---|
| 柳寒衣 | 切磋 | 首遇后 | 点到为止的比剑：按「同阶」斗法判定，**不会受伤**。胜利好感 +3、修为 +5%；落败好感 +1（「再来」）。两次切磋至少相隔 4 次行动 |
| 白芷 | 问诊 | 首遇后 | 治好轻伤（10×）、重伤（50×）或中毒（15×），比集市买药略便宜；好感 ≥ 60（拜师）后半价 |
| 钱多多 | 买情报 | 好感 ≥ 30 | 原文「≥30 · 情报生意」：秘境开启时间、某 NPC 的位置、某突破材料的来源，每条 20× |
| 苏夜璃 | 交易 | 好感 ≥ 30 | 原文「≥30 · 交易」：用一颗正道丹药（回春丹、续命丹、清心丹）换一张魔道功法残卷 |
| 赵承霄 | 切磋 | 和解线 | 同柳寒衣的切磋，但按「高一层」判定；胜利好感 +5 |
| 林小婉 | 同修 | 被救后 | 一起打坐：心境 +5，好感 +2。不消耗额外时间 |
| 玄清真人 | 请教 | 成为问剑宗弟子 | 修为 +10%，每个小层级只能请教一次；好感 ≥ 30（入室弟子）后改为修为 +15% |
| 阿九 | 打听妖族 | 好感 ≥ 30 | 原文「≥30 · 化形」后「可以向她打听妖族领地的情报」：告诉你下一次在山野外出探索的事件类别，并且这次探索若是妖兽事件，多出「以礼相待」选项（必定不战而退） |
| 星衍子 | 算卦 | 首遇后 | 原文首遇的「一卦十灵石」延续为日常：10×，得到一条关于「下一个危险事件」的预言（提前知道类型） |
| 小石头 | 指点 | 收他为徒后 | 原文「每次回村可以指点他一次（两次之间至少相隔 5 次行动）」：他的境界提升一级，记 1 点陪伴 |
| 道侣 | 双修 | 结为道侣后 | 只在洞府：本次拜访改为一次闭关，修为按 systems 11.2「在洞府闭关修为 +15%」结算（耗时按闭关算） |

## 七、好感的上限与限制

### 7.1 日常互动只能把好感推到 60

叙话、送礼、专属往来这些**日常互动，最多只能把好感推到 60**。60 以上只能通过关系线事件、终章、事件里的选择（例如 D01 救林小婉 +50）来提升。

这样：

- 30、60 两个阶段，勤于往来的玩家可以靠日常互动够到，保证关系线不会卡住；
- 90 这一档（道侣、结拜、托孤、传承……）必须经历过真正的大事才能达到，分量不会被「天天送礼」冲淡。

### 7.2 与已有上限的关系

原文中已有的上限照常生效，并且比 60 更严时以更严的为准：

| 上限 | 出处 |
|---|---|
| 所有 NPC 好感上限 50 | 天赋「太上忘情」 |
| 林小婉好感上限 50 | D01 选择「与她交易」 |
| 好感上限提升为 100 | D10「以命换命」选择换命 |

### 7.3 好感不会自然下降

不拜访也不会掉好感。NPC 会按自己的轨迹变化（例如林小婉的境界跟随玩家成长），但对你的好感只由事件和你的选择改变。

### 7.4 显示

好感不显示具体数字，而是显示关系称谓：

| 好感 | 称谓 |
|---|---|
| ≤ -50 | 敌对 |
| -49 ～ -1 | 冷淡 |
| 0 ～ 29 | 相识 |
| 30 ～ 59 | 相熟 |
| 60 ～ 89 | 知己 |
| ≥ 90 | 至交（结为道侣后显示「道侣」） |

称谓旁边用一条进度条表示离下一档还有多远。无名老丐的隐藏好感**不显示**；持有传说天赋「因果之眼」时才能看到（「能看到所有 NPC 的隐藏好感」）。

## 八、需要负责人确认的地方

以下都是本文新增的规则，原文没有写：

1. **日常互动的好感上限 60**（7.1）：这是本文最重要的一条取舍，决定了关系线的节奏。
2. **柳寒衣每 6 次行动换一次地方**（第二节）：原文只写了「山野、问剑宗」两处出没地。
3. **苏夜璃好感 ≥ 30 才能拜访、阿九化形后才能拜访**（第二节）：照原文的关系线推出来的，但原文没有明说。
4. **每位 NPC 的喜好**（5.2）和**专属往来的具体数值**（第六节）：首版初值，模拟测试时再调。
5. **闲话池**（4.3）：每位 NPC 4–6 条，是新增的文字内容，需要另外写。

## 九、配置字段

```json
{
  "id": "npc_bai_zhi",
  "visit_locations": ["market", "sect_danding"],
  "visit_unlock": { "met": true, "affection_min": -49 },
  "stance": "righteous",
  "gifts": {
    "favorite": ["jiuye_lingzhi"],
    "like": ["ninglu_cao", "chixue_shen", "lingquan_shui", "tag:recipe"],
    "dislike": ["hulang_yao"]
  },
  "special": { "type": "heal", "unlock": { "met": true } },
  "gossip_pool": ["gossip_bai_zhi_01"]
}
```

| 字段 | 含义 |
|---|---|
| `visit_locations` | 能在哪些地点拜访；会换地方的 NPC 另加 `wander_every_actions` |
| `visit_unlock` | 开始能拜访的条件 |
| `stance` | 立场：`righteous`（正）、`demonic`（邪）、`neutral`（不在意），用于 4.2 |
| `gifts` | 心头好、喜欢、讨厌；可以写物品 ID，也可以写 `tag:` 加物品标签 |
| `special` | 专属往来的类型和开放条件 |
| `gossip_pool` | 闲话池里的文字 ID |
