## 二、心境的自然恢复

原文只写了心境怎么升降，没有写不管它会怎样。规则：

- **只会往 50 回升，不会自己下降。** 心境低于 50 时，每次闭关修炼（三种方式都算）心境 +3，最多回到 50。
- 心境 ≥ 50 时不会自然变化。想要更高，要靠事件、清心丹、静室、道侣、心境类选项。
- 洞府的静室（systems 6.2）效果照常叠加：在有静室的洞府闭关，静室给的心境与自然恢复一起生效，但自然恢复部分同样只补到 50 为止。

**为什么是 50 而不是初始的 60**：心境 < 40 才会容易触发心魔（content-expansion 0.1）。自然恢复到 50 能让玩家走出心魔的高发区，但不会把好不容易攒到 80 的心境「拉平」，也不会让「心境 ≥ 60」「心境 ≥ 70」的事件条件变得白给。

## 三、伤势、中毒与状态的恢复

原文的恢复方式里有按年写的部分，这里统一换成行动次数：

| 状态 | 自然恢复 | 其他恢复方式 |
|---|---|---|
| 轻伤 | 之后的第 2 次行动结算完毕时自愈（原文「2 次行动后自愈」） | 回春丹；白芷问诊 |
| 重伤 | **不会自愈**。重伤期间的闭关修炼自动改为「闭关疗伤」：修为照常按重伤 -50% 获得，累计 **2 次**闭关后痊愈（原文「闭关疗伤 2 年」，炼气期 1 年 = 1 次闭关） | 续命丹；白芷问诊 |
| 中毒 | **不会自愈** | 解毒丹；W04 运功逼毒；白芷问诊 |
| 心魔种 | **不会自愈** | 清心丹；W05「斩心魔」成功 |
| 根基受损 | 永久 | 打磨根基、洗髓丹、洗髓类机缘 |

**中毒的寿元损失**：原文「每过 1 年额外损失 1 年寿元」，换算成行动：中毒期间，**每次行动额外损失与本次耗时相同的寿元**。也就是中毒时时间过得像平时的两倍快。这样在任何境界下比例都一样：炼气期一次闭关多损 1 年，大乘期多损 150 年，但大乘的寿元上限也是一万年，不会一次就要命。

**重伤的限制**照原文：重伤时不能进入秘境（systems 9.1）；再次重伤会死亡（见 6.4）。

**闭关会被打扰**（本文新增）：在野外闭关（山野、落霞谷，包括普通修炼、全力冲关、打磨根基、闭关疗伤）时，有 **10%** 的概率被妖兽或仇家找上门，触发事件「闭关遇袭」。在洞府闭关：没有护山阵时 **5%**，建了护山阵就不会被打扰。

- 遇袭时可以迎战（斗法，同阶），也可以中断闭关逃走。
- **重伤期间遇袭最危险**：迎战时战力只有一半；逃跑失败会再受一次重伤，也就是身死道消（6.4 的保命顺序照常生效）。
- 这样做的原因：如果重伤后原地闭关就绝对安全，谨慎的玩家永远不会死，「再次重伤会死亡」形同虚设。洞府和护山阵因此多了一层实际用处：那里是安全的养伤之地。

**突破材料保底**（本文新增）：筑基以后，修为已经圆满、却缺下一境界的突破材料时，每外出探索 **12** 次，必定出现一次事件「灵物出世」：可以斗法去抢（两人，同阶），胜了得到一份下一境界的突破材料；也可以花 120× 灵石收购；或者放手，12 次之后还会再来。

- 这样做的原因：首轮模拟里，停在金丹、元婴的局，圆满之后平均还要空等 50–80 次决策才寿终，这段时间只能反复探索碰运气，单局也因此超出 120–180 次决策的目标。保底让等待最多十来次，抢夺又带来一次实打实的风险。

## 四、背包满了怎么办

### 4.1 什么占格子

背包 20 格，储物戒 +5 格（systems 第 3 节开头）。

| 占格子 | 不占格子 |
|---|---|
| 丹药、符箓、灵草与材料（每格同种叠 10 个） | 已装备的武器、防具、饰品 |
| 未装备的装备（每件 1 格） | 已学会的功法、已掌握的丹方 |
| 功法残卷、未学习的完整功法、丹方 | **突破材料**（筑基丹、凝金草……渡劫雷木） |
| | **剧情物品**（推荐信、血煞令、刺客令牌、遗物、戒指、钥匙……） |

突破材料和剧情物品放在单独的「要物」栏里，不限数量。它们关系到主线和结局，不能因为背包满而丢失。

### 4.2 获得物品时背包满了

弹出一个取舍界面，列出新得到的物品和背包里的东西，玩家选一项：

1. **丢掉一件旧的**：选背包里任意一件（一叠）丢掉，放入新物品。
2. **放弃新的**：新物品不要了。
3. **寄放洞府**（拥有洞府时）：新物品直接送回洞府的储物处。洞府储物处 30 格，只有回到洞府时才能取用。这一条是本文新增的。

取舍不消耗时间。一次获得多件物品时，逐件处理。

### 4.3 集市里背包满了

不能购买，提示「背包放不下了」。可以先卖掉东西再买。

## 五、扣不够怎么办

### 5.1 主动选择的代价

选项需要付出的东西（灵石、物品、修为、贡献、寿元）**不够时，这个选项不能选**，显示为灰色并写明缺什么。例如「走后门（灵石 -100×）」在灵石不足时置灰。

例外：写明「以寿元换取」的选项（W09 鬼市、D05 以自身寿元代替、D10 以命换命），只要扣完寿元后不会立刻死亡就可以选；会立刻死亡时置灰。

### 5.2 被动的损失

事件结果、斗法落败造成的损失（「灵石 -50%」「灵石 -200×」「丢失 1 件随机物品」「修为 -30%」）**扣到 0 为止**，不欠债：

- 灵石：扣到 0。
- 修为：扣到当前小层级的 0%，**不会因此跌落层级**。只有原文明确写了「跌落一个小层级」的结果才会降层。
- 物品：「丢失 1 件随机物品」从背包里随机选，**不会选到**已装备的物品、要物栏里的突破材料和剧情物品；背包是空的就不丢。
- 贡献：累计贡献和可用贡献都扣到 0。

## 六、同一步里的结算顺序

一次选择（或一次行动）产生多个效果时，严格按下面的顺序结算。顺序固定，同样的局面一定得到同样的结果（每日天命的重放依赖这一点，systems 7.3）。

### 6.1 总顺序

| 步骤 | 内容 |
|---|---|
| 1 | **支付代价**：扣除选项写明的灵石、物品、贡献、寿元 |
| 2 | **判定**：掷骰子（判定随机流），决定成功、失败或斗法档位 |
| 3 | **档位与伤势的减免**：按 6.3 的顺序 |
| 4 | **时间推进**：年龄 += 耗时 × 时间系数（及时间类修正，见 6.5）；中毒额外损失寿元 |
| 5 | **数值结果**：修为、根基、气运、心境、道心、好感、灵石、贡献等，按 6.2 计算修为 |
| 6 | **物品**：获得与失去；背包满时进入 4.2 的取舍 |
| 7 | **状态**：新的伤势、中毒、心魔种等；轻伤、重伤的恢复计数推进 |
| 8 | **生死判定**：按 6.4 |
| 9 | **修为满额升层**：满 100% 自动进入下一小层级，溢出部分保留（见 6.2） |
| 10 | **寿元判定**：年龄 ≥ 寿元上限 → 结束本局，进入结局判定（systems 10.1） |
| 11 | **计时器**：持续型世界状态、冷却、定时后续的行动计数 -1，到期的进入强制队列 |
| 12 | **记录**：宿命进度、因果录条件、人生日志 |
| 13 | **钳制**：所有属性钳制到第一节的范围 |
| 14 | 存档 |

### 6.2 修为怎么算

> **获得的修为** = 基础值 × (1 + 加成之和) × 惩罚之积

- **基础值**：普通修炼为「1 ÷ 每层次数」（systems 1.2）；事件写明的「修为 +X%」就是 X%。
- **加成相加**：功法、天赋、丹药、洞府、聚灵阵、灵脉、世界状态（天降异象 +20%、灵气潮汐 +50%）等加成相加。同一类加成只取最高的一项（例如学了两本修炼类功法，只算加成更高的那一本，systems 2.1「同类取最高」）。
- **惩罚相乘**：重伤 ×0.5、根基 < 30 ×0.8、丹毒 ≥ 5 ×0.8、退潮 ×0.7、末法每档 ×0.9……依次相乘。
- **溢出**：修为超过 100% 时进入下一小层级，多出的部分带到新的一层；但**到了大境界圆满就停在 100%**，多出的部分作废，必须突破才能继续。

**例**：筑基中期（每层 3 次，基础 33%），天生道体（+20%）、聚灵玉佩（+10%），根基 25、丹毒 6：33% × (1 + 0.2 + 0.1) × 0.8 × 0.8 ≈ 27%。

### 6.3 斗法结果的减免顺序

斗法掷出档位后，下面的效果按顺序检查，**每一条只在仍然适用时生效**：

1. **档位降级**（惨败 → 落败）：金刚不坏体（每个大境界一次）→ 玄龟甲（每局 3 次）。已经被前一项降级过的，后一项不再消耗次数。金刚符属于「借助道具」，在判定前就已经用掉，按符箓说明生效。
2. **伤势减轻**（重伤 → 轻伤）：铜皮铁骨、不灭金身、金蚕宝衣，有任意一项即可，不重复生效。
3. **受伤概率**：铜皮铁骨（-30%）、铁布衫（-15%）、青云道袍（-10%）等「受伤概率降低」的效果相加，用来判定「险胜」时是否真的受伤。

天魔解体（「惨败直接改为大胜」）在第 1 步之前生效，生效后跳过其余减免。

### 6.4 生死判定与保命的顺序

以下情况会死亡：已经重伤时再次重伤；惨败且原本已重伤；事件、斗法或突破失败的结果写明死亡。（寿元耗尽不在这里判定，属于第 10 步的寿终。）

即将死亡时，按下面的顺序检查保命效果，**第一个满足的生效，其余不消耗**：

1. **林小婉舍身相救**：好感 ≥ 90，且这是你第一次将死于斗法（原文：「与『九死一生』不叠加，优先触发她的救援」）
2. **天赋「九死一生」**：每局一次，转为重伤，根基 -20
3. **替身符**：免死一次，消耗一张
4. **看广告复活**（README 第 5 节第 11 条）：以上都不满足、且本局还没用过时，弹出「看一段广告，留住这条命」。玩家选择看完后，**恢复原样**：这一次致命的结果作废，状态保持出事前的样子（原来有伤还是有伤，没伤还是没伤），不额外加伤，也不治伤；之后的规则一切照常，不会因为看过广告而更安全或更危险。选择不看，或广告没有看完，按死亡结算。每局一次（负责人 2026-10-25 确认，原为「转为重伤」）
5. **天赋「万古长青」**：只对寿元耗尽生效（第 10 步），不在这里

都不满足时，本局以「身死道消」结束，并按死因记入因果录。

广告拉取失败（没有可播放的广告）时，提示「暂时没有可播放的广告」，并提供「重试」和「坦然受之」两个按钮；玩家选择坦然受之才按死亡结算，不会因为网络问题直接判死。

### 6.5 时间的修正

| 来源 | 修正 |
|---|---|
| 天赋「光阴道体」 | 所有行动耗时 ×0.75 |
| 灵宠「青鸾」跟随时 | 外出探索耗时 ×0.8 |
| 天赋、出身中「学习功法时间减半」 | 学习功法耗时 ×0.5（落魄书生和过目不忘不叠加，仍是 ×0.5） |

多项修正相乘。

### 6.6 突破失败时看广告免罚

大境界突破失败（systems 1.5）时，在结算失败后果之前，弹出「看一段广告，免除这次失败的后果」：

- **每个大境界一次**：例如冲击筑基时用过了，冲击金丹时还可以再用一次。
- 看完后，失败后果表里的全部后果都免除：修为、根基不扣，不受伤，不跌落层级，不会死于天劫。
- **这次突破仍然算失败**：境界不变，仍然要再修炼一次才能重新尝试（systems 1.5），防止靠广告反复刷突破。
- 选择不看，或广告没有看完，照常结算失败后果；如果失败后果是死亡，接着进入 6.4 的保命顺序（看广告复活仍然可以用）。
- 广告拉取失败时的处理同 6.4。

## 七、负责人已确认的取舍

以下由本文新增或做了取舍的规则已由负责人确认（2026-10-25）：

1. **心境自然恢复到 50**（第二节）：每次闭关 +3。
2. **洞府储物处**（4.2）：拥有洞府时可以把新物品寄放回洞府，30 格。
3. **突破材料和剧情物品不占背包**（4.1）。
4. **修为加成相加、惩罚相乘**（6.2）：已写入 README 第 5 节「已经做出的关键决定」。
5. **落魄书生与过目不忘的学习时间不叠加**（6.5）：仍是减半，不会变成四分之一。
6. **闭关会被打扰**（第三节）：野外闭关 10% 遇袭，洞府 5%，有护山阵不会遇袭；重伤时遇袭逃跑失败即再受重伤。已写入 README 第 5 节。
7. **突破材料保底**（第三节）：圆满后缺材料，每探索 12 次必定出一次「灵物出世」（2026-10-26）。
